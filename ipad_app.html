Usage Guide
For sales staff — critical points only
I. Standard Receipt Workflow
1
Select brand HP USA or VVS in the masthead
2
Search for the customer by name, SO# or Appt ID
3
Choose document type: Sales Receipt Sales Invoice Deposit
4
Fill in line items, amount, and select payment method
5
Tap Generate — Google Doc & PDF links appear immediately
II. Generate Invoice + Receipt Together
Tip Use when the customer pays immediately — system creates Sales Invoice first, then Sales Receipt automatically.
1
Select a customer → the charcoal banner "Generate invoice + receipt together" appears
2
Check the checkbox → fill in line items, amount, and payment method
3
Tap "Generate Invoice + Receipt" — watch progress: ① Invoice → ② Receipt → ✓ Done
III. Important Notes
! A Sales Receipt requires a Sales Invoice first. If no invoice exists, the system will block submission. Use combo mode or create a Sales Invoice first.
! Always verify HP USA / VVS brand before searching. Wrong brand = no results found.
! $25 Diamond Viewing: Use the dedicated $25 Diamond Viewing Deposit button — no need to select a doc type manually.
✓ Tax Toggle: Defaults to ON. Staff can manually turn it off if the customer is tax-exempt.
IV. Document Types & Payment Methods
Document Types
  • Sales Receipt — Full payment received
  • Deposit Receipt — Partial payment
  • Sales Invoice — Payment request
  • Deposit Invoice — Deposit request
When to Use What
  • Full payment → Sales Receipt
  • Deposit first → Deposit Invoice
  • Send quote → Sales Invoice
  • Diamond viewing → $25 Deposit

V. Refer a Friend Program
1
In the Financial Summary section, enable the "Refer a Friend" toggle
2
Enter the referrer's full name (required) — $100 discount applied pre-tax immediately
! Each order can only use the referral discount once. If already used, the system locks it automatically.
VI. Walk-in Customer / New Intake
Tip Use when a customer walks in without an existing record or appointment.
1
Tap "Walk-in / New Customer Intake" below the search bar
2
Fill in customer name, contact, visit type, and source — submit to sheet
3
After submit: choose to generate $25 Diamond Viewing, Receipt / Invoice, or start a new intake
! For walk-ins leave Calendly Event UID blank. For booked appointments, paste the Calendly UID to link the record automatically.
VII. Troubleshooting
!
"Submit failed" error → Check network connection, reload the page and try again
!
Customer not found → Make sure the correct brand HP USA / VVS is selected
!
Need to reprint → Go to Google Drive → customer folder → find the PDF file
